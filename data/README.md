# Dataset

Download version 1 of the [Facility Management Unified Classification Database (FMUCD)](https://data.mendeley.com/datasets/cb8d2nsjss/1) from Mendeley Data.

Extract and place the CSV at this exact relative path:

```text
data/Facility Management Unified Classification Database (FMUCD).csv
```

The file is approximately 1.44 GB. It is excluded from Git, so it must be downloaded separately when using a cloned copy. The notebook already uses this relative path and does not require an absolute local path.

## Reference

Pampana, A.K., Jeon, J., Yoon, S. and Weidner, T.J. (2024) *Facility Management Unified Classification Database (FMUCD)*, version 1. Mendeley Data. doi: [10.17632/cb8d2nsjss.1](https://doi.org/10.17632/cb8d2nsjss.1). CC BY 4.0.
